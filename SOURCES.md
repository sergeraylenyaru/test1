# Источники и изображения

## Игровой ориентир

Механики проекта вдохновлены классическими играми «три в ряд», включая **Candy Crush Saga**: ограниченные ходы, цели, каскады, спецкомбинации из четырёх и пяти элементов, Т/Г-комбинации, объединение спецэлементов, бустеры и звёзды.

- Оригинальная игра: https://www.king.com/game/candycrush
- Публичный пример проекта с механиками Candy Crush, просмотренный при исследовании: https://github.com/btuhany/CandyCrushSagaClone-Unity

Сайт King был недоступен из рабочей среды. Сравнение актуальных рейтингов популярности не проводилось; утверждение «самая популярная игра» не подтверждается. Код этой игры написан самостоятельно, без копирования кода, уровней, звуков или графики Candy Crush.

Оригинальные JPG сохранены без изменений. CSS задаёт индивидуальные области кадрирования и единый размер игровых пачек, добавляет перспективу, свет и тень. Изображения загружаются локально: внешние ссылки для игры не нужны.

Источник не содержит отдельной лицензии на эти фотографии; открытая доступность репозитория не означает свободную лицензию на изображения. Названия и изображения марок принадлежат их правообладателям. Проект не связан с Philip Morris International.

## Остальное оформление

Шкаф, полки, подсветка, эффекты, частицы, пиктограмма сайта и звуки созданы для проекта средствами CSS, SVG и Web Audio. Внешние шрифты и библиотеки не используются.
