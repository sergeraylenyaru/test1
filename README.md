# Brand Match

Браузерная игра «3 в ряд»: шесть марок Philip Morris, поле 8×8, 30 ходов, каскады, подсказка и локальный рекорд. Независимый проект, не связанный с Philip Morris International.

## Запуск

Откройте `index.html` в браузере либо запустите статический сервер:

```sh
cd /workspace/test1
python3 -m http.server 3000 --bind 0.0.0.0
```

Зависимости и сборка не нужны. Соседние фишки выбираются двумя нажатиями; обмен без совпадения отменяется и не расходует ход. Каскады дают растущий множитель. Если доступных комбинаций нет, поле обновляется бесплатно. Рекорд сохраняется в localStorage, если браузер разрешает хранение.

## Проверки

```sh
node --test tests/engine.test.js
```

Проверяются генерация полей, совпадения, границы строк, падение фишек, подсказки и полные случайные партии.
