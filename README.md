# Brand Match — Шкаф комбинаций

Браузерная головоломка «три в ряд» с деревянным шкафом и настоящими изображениями пачек Marlboro и Sampoerna. Независимый проект, не связанный с Philip Morris International. Курение вредит здоровью.

## Что есть в игре

- Поле 7×7, четыре варианта пачек из портфеля Philip Morris.
- 12 уровней с целями по очкам и сбору двух видов пачек, ограниченные ходы.
- Каскады с растущим множителем, частицы, плавные обмены и падение.
- Четыре в ряд создают очистку линии; Т/Г создают взрыв; пять в ряд создают призму, собирающую одну марку.
- Объединение двух спецпачек усиливает эффект. Спецпачки также активируются цепочкой.
- Подсказка и автоматическое перемешивание поля без доступных ходов.
- Бустеры: убрать пачку без расхода хода (3 на уровень), перемешать шкаф (2 на уровень).
- Перетаскивание мышью, сенсорные нажатия и управление клавиатурой.
- Звук с выключателем, звёзды, бонус за оставшиеся ходы, сохранение открытых уровней и рекорда.
- Мобильная вёрстка, режим уменьшенного движения. При недоступном localStorage игра работает без сохранения.

Источники изображений и сведения об их подготовке: [SOURCES.md](SOURCES.md).

## Запуск

Откройте `index.html` в браузере либо запустите статический сервер:

```sh
cd /workspace/test1
python3 -m http.server 3000 --bind 0.0.0.0
```

Сборка и установка пакетов не нужны. Все изображения включены в `assets/`; сохраняйте эту папку при переносе игры. Игра не обращается к внешним сервисам.

## Управление

Нажмите на две соседние пачки либо перетащите одну на соседнюю ячейку. Обмен без комбинации отменяется без расхода хода. На клавиатуре используйте Tab для выбора пачки, стрелки для перехода между соседними ячейками и Enter/Пробел для выбора.

Призму можно обменять с любой соседней пачкой. Две спецпачки можно обменивать без совпадения. Обычная спецпачка запускается при попадании в комбинацию или взрыв.

## Проверки

```sh
node --test tests/engine.test.js
node --check app.js
```

Проверяются генерация и доступность ходов, границы поля, все виды спецкомбинаций, цепные активации, падение, призмы и полные случайные партии.

Для ручной проверки: сделайте допустимый обмен (очки растут, ход расходуется), недопустимый обмен (поле возвращается, ход сохраняется), примените бустер, проверьте перетаскивание, завершение уровня и повторную загрузку после открытия следующего уровня.
